## 1. Private Infrastructure Prerequisites

Before deploying Crystal Heimdall to internal servers or clouds:
1. **Repository Access:** Ensure the deployment server has deploy key, SSH, or token access to `https://github.com/Crystal-Studio-Labs/Crystal-Heimdall.git`.
2. **Secrets Provisioning:** Populate `.env` from the official **Crystal Studio Labs 1Password / Vault** vault. Do not commit `.env`.
3. **Network Boundary:** 
   * Expose public status endpoints (`/`, `/overview`, `/incidents`, `/docs`) via reverse proxy (Caddy / Nginx / Vercel Edge).
   * Restrict access to `/dashboard*` via **2FA TOTP gate**, **Cloudflare Zero Trust Access**, or **Tailscale** private subnets.

## 2. Production Build Execution

Compile the optimized client bundle and TypeScript server:

```bash
# 1. Install dependencies strictly from lockfile
npm ci

# 2. Compile Vite client and TypeScript server
npm run build

# 3. Verify with dual automated verification suites
node test-smoke.mjs
node test-pentest.mjs
```

Build outputs:
* `dist-client/`: Static Single-Page Application assets.
* `dist-server/`: Compiled Node.js ESM server binaries.
* `docs/`: Standalone GitHub Pages showcase website and static assets.
* `data/heimdall.db`: LibSQL / SQLite persistent database.

## 3. Option A: Vercel Serverless Hosting (Active Production)

Crystal Heimdall is currently deployed and running in production on [Vercel](https://vercel.com):

* **Live URL:** [https://crystal-heimdall.vercel.app](https://crystal-heimdall.vercel.app)
* **Configuration:** Pre-configured in [`vercel.json`](file:///d:/Projects/Crystal-Heimdall/vercel.json).
* **Serverless Functions:** Routed via `api/index.js` Express adapter.

### Required Environment Variables in Vercel:

| Variable | Required | Description |
|---|---|---|
| `TURSO_DATABASE_URL` | **Yes** | Remote LibSQL database URL (`libsql://heimdall-crystal.turso.io`). Provides state persistence across serverless executions. |
| `TURSO_AUTH_TOKEN` | **Yes** | Turso authentication token. |
| `JWT_SECRET` | **Yes** | High-entropy secret for operator session signing. |
| `TOTP_SECRET` | **Yes** | Base32 seed for operator 2FA verification. |
| `VAPID_PUBLIC_KEY` | Optional | Auto-generated by Heimdall if not provided. |
| `VAPID_PRIVATE_KEY` | Optional | Auto-generated and encrypted with AES-256-GCM if not provided. |
| `DISCORD_WEBHOOK_URL` | Optional | Webhook URL for Discord incident embeds. |
| `TELEGRAM_BOT_TOKEN` | Optional | Telegram bot token for instant alert dispatch. |
| `TELEGRAM_CHAT_ID` | Optional | Telegram chat or group identifier. |

## 5. Option C: Docker Container Deployment

Run in an isolated container with volume persistence for SQLite:

### `Dockerfile`
```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
ENV PORT=3030
COPY --from=builder /app/package*.json ./
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/dist-client ./dist-client
COPY --from=builder /app/dist-server ./dist-server
COPY --from=builder /app/data ./data

EXPOSE 3030
CMD ["node", "dist-server/index.js"]
```

### `docker-compose.yml`
```yaml
version: '3.8'

services:
  crystal-heimdall:
    build: .
    container_name: crystal-heimdall
    restart: always
    ports:
      - "3030:3030"
    environment:
      - PORT=3030
      - NODE_ENV=production
      - DATABASE_URL=file:/app/data/heimdall.db
      - JWT_SECRET=${JWT_SECRET}
      - TOTP_SECRET=${TOTP_SECRET}
      - DISCORD_WEBHOOK_URL=${DISCORD_WEBHOOK_URL}
      - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
      - TELEGRAM_CHAT_ID=${TELEGRAM_CHAT_ID}
    volumes:
      - ./data:/app/data
```

Launch with:
```bash
docker compose up -d --build
```

## 6. Option D: PM2 Process Manager (Private VPS)

```bash
# 1. Install PM2
npm install -g pm2

# 2. Launch background service
pm2 start dist-server/index.js --name "crystal-heimdall"

# 3. Configure system boot startup
pm2 save
pm2 startup
```

## 7. Option E: Render (24/7 Continuous Monitoring)

1. Connect repository `Crystal-Studio-Labs/Crystal-Heimdall` to Render.
2. Render reads [`render.yaml`](file:///d:/Projects/Crystal-Heimdall/render.yaml) automatically:
   * **Runtime:** Node.js
   * **Build Command:** `npm run build`
   * **Start Command:** `npm start`
   * **Disk:** Mounts `/app/data` to preserve database across restarts.

## 8. Option F: Fly.io (Free Edge VM & Persistent Volume)

```bash
# 1. Create persistent storage volume
fly volumes create heimdall_data --size 1 --region iad

# 2. Deploy using fly.toml
fly launch --no-deploy
fly deploy
```
